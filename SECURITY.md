# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.
Report them privately from the repository's **Security** tab, with **Report a vulnerability**.

Include what is affected, how to reproduce it, and what it lets an attacker do.
You will get a reply there, and the fix and an advisory will be published once ready.

## Scope

A deck is a program: opening a deck you trust runs its code with your permissions, by design.
Reports about that are not vulnerabilities, but ways around the trust prompt or out of safe mode are.

## Supported versions

Only the latest version on `main` gets security fixes.
